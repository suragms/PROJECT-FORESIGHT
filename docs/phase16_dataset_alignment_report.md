## Risk Scoring Compatibility

**Finding: `IMPLEMENTATION DIFFERENCE — RISK ENGINE IS NOT FULLY FORECAST-DRIVEN`**

The current `src/risk_scoring.py` derives all demand signals from the historical rolling average (`mean(units_sold)` over a recent window), not from the frozen forecast model output (`final_predictions.parquet`).

This means:
- Stockout risk is based on **historical average demand**, not on what the model predicts demand will be
- This is a functional, reasonable implementation for a planning tool
- It does not satisfy the Zidio specification's requirement for forecast-driven stockout risk scoring

All other risk inputs (lead time, on-hand inventory, on-order quantity, safety stock, reorder point) are correctly sourced from actual data artifacts.

**Status:** PARTIAL — risk engine is functional but not forecast-integrated. Forecast-driven risk would require consuming `final_predictions.parquet` in `src/risk_scoring.py`. This is a Phase 17 enhancement, not a retroactive fix.

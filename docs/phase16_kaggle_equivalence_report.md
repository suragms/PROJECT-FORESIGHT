## 2. Rationale

The current repository synthetic data is **independently generated** by `src/generate_synthetic_retail.py`. The Kaggle Synthetic Retail 10M dataset was not downloaded for direct comparison because the Kaggle CLI is not available on this system.

However, strong circumstantial evidence supports the **DIFFERENT DATASET** classification:

### Scale Difference

| Metric | Current Repository | Kaggle 10M (claimed) |
|--------|-------------------|---------------------|
| Transaction rows | 1,461,000 | ~10,000,000 |
| Scale factor | 1× | ~6.8× |

The Kaggle dataset claims approximately 10 million transactions. The repository has 1,461,000 sales records. This is a 6.8× scale difference.

### Key Format Evidence

| Entity | Current Repository | Expected if Kaggle |
|--------|-------------------|-------------------|
| Store IDs | `STORE_001` to `STORE_030` | Unknown — requires download |
| SKU IDs | `SKU_00001` to `SKU_05000` | Unknown — requires download |
| Customer IDs | `CUST_000001` to `CUST_010000` | Unknown — requires download |

### Generator Evidence

The file `src/generate_synthetic_retail.py` contains the complete generation logic with hardcoded parameters:
- `numpy.random.seed(42)`
- 30 stores, 5,000 SKUs, 10,000 customers
- Sales generated for only 10 stores × 100 SKUs
- No reference to Kaggle download or external data source
